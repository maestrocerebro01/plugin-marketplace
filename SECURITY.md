# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue:

- Preferred: use GitHub's private vulnerability reporting for this repository (Security tab → Report a vulnerability).
- Alternative: email sentientseraphim@gmail.com with details and reproduction steps.

Please do not disclose the issue publicly until it has been addressed.

## Supported Versions

Only the `main` branch is actively maintained; there are no other supported release branches at this time.
